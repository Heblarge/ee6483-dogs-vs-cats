This note records the server-side verification performed after the reproducibility fixes.
It is an audit of the frozen recipes, not a new hyper-parameter search, and it does not
replace the original report numbers.

  `/projects/embodied/zihanshu001/ee6483/recheck_20261111/code`

scikit-learn 1.9.1 and pyarrow 26.0.1. AMP is not bit-exact across software/hardware,
so agreement is assessed at the result level rather than the last decimal place.

## Interpretation

The recheck supports reproducibility of the reported conclusions without cherry-picking:
the selected tau is unchanged, the imbalance improvement remains large, the ensemble
validation result is reproduced exactly, and the regenerated submission has the same class counts
(byte identity was not preserved as evidence). It cannot
prove zero generalisation error or remove the validation-selection bias already disclosed
in Section 10.3; that would require a new untouched labelled holdout set.
